# DSI 2023 Full-Paper Format Matrix

Rules extracted from the official template
`2023-DSI-Annual-Meeting_FINAL-Full-Paper-Submission-TEMPLATE.docx`
(guideline pages 1–4 = the red instructions; pages 5–6 = the worked "Smith & Johnson" example).

Each rule lists: **ID · Rule · Source page**. Compliance against `main-v3.tex` is in
the companion file `compliance-audit.md`.

---

## A. Page Setup

| ID | Rule | Source |
|----|------|--------|
| A1 | Margins: 1 inch on all four sides (left, right, top, bottom). | p.1, p.3 (Default Style) |
| A2 | Page size: 8.5 × 11 inches (letter). | p.3 |
| A3 | Font: **Arial, size 11** throughout. | p.1, p.3 |
| A4 | Line spacing: **single (1.0)**. Word default is 1.15 — must be changed. | p.1, p.3 |
| A5 | Paragraph spacing: **no space before or after** paragraphs. | p.3 (Default Style) |
| A6 | Text alignment: **justify = left** (i.e. left-aligned / ragged right, NOT full-justified). | p.3 (Default Style) |
| A7 | **No page numbers.** | p.1, p.3 |
| A8 | Do not use pre-defined Word styles. | p.1 |
| A9 | Sections separated by just **1 blank line (1 hard return)**. | p.1 |
| A10 | Final PDF size must not exceed **1 MB**. | p.3 |
| A11 | Total size of all figures/graphics must not exceed **500 KB**. | p.3 |
| A12 | Max length ~**35 pages** incl. figures, tables, references. | p.3 |
| A13 | Language: traditional English or Greek characters only (no Korean/Chinese). | p.3 |

## B. Running Header (every page)

| ID | Rule | Source |
|----|------|--------|
| B1 | **Left side:** 1st Author Last Name, 2nd Author Last Name (use "et al." if more than two authors). | p.1, ex. p.5 |
| B2 | **Right side:** Short Title, up to 8 words, **aligned right**. | p.1, ex. p.5 |
| B3 | A **horizontal rule** sits directly below the header line. | ex. p.5–7 |
| B4 | Header repeats on every page; no page numbers anywhere. | p.1, p.3 |

## C. Title Block (first page, centered)

| ID | Rule | Source |
|----|------|--------|
| C1 | First line must be **"DECISION SCIENCES INSTITUTE"** — keep it, **bold**, centered. | p.1, ex. p.5 |
| C2 | Paper title: **centered**. | p.1 |
| C3 | Paper title: **not boldface**. | p.1 |
| C4 | Title capitalization: p.1 bullet says "capitalize only the first Letter" (sentence case); the worked example p.5 uses Title Case. **Template is internally inconsistent — see audit.** | p.1 vs ex. p.5 |
| C5 | Author block below title, centered: **Full Name / Affiliation / Contact info** for each author. Contact = complete address, email, telephone. | p.1, p.3, ex. p.5 |
| C6 | Author block is **single-spaced and centered** below the title. | p.3 |
| C7 | Do **not** use titles such as Dr., Professor, etc. in author info. | p.3 |

## D. Abstract & Keywords

| ID | Rule | Source |
|----|------|--------|
| D1 | The word **"ABSTRACT"**: ALL CAPS, **boldface**, **centered**. | p.1 |
| D2 | Abstract body limited to **100 words**. | p.1 |
| D3 | **KEYWORDS:** label followed by up to 5 keywords. Label shown **underlined** in template ("KEYWORDS:"). | p.1, ex. p.5 |
| D4 | Prefer keywords from the DSJ or DSJIE keyword list. | p.1 |

## E. Section Heading Levels

| ID | Rule | Source |
|----|------|--------|
| E1 | **Level 1** (major/first-level, e.g. INTRODUCTION, LITERATURE REVIEW, REFERENCES): **ALL CAPS, bold, left-aligned.** | p.1, p.2 |
| E2 | **Level 2** (below L1): **bold, only the first letter capitalized** (sentence case), left-aligned. | p.2 |
| E3 | **Level 3** (below L2): **underlined, NOT bold, only first letter capitalized** (sentence case), left-aligned. | p.2 |
| E4 | Sections are **not numbered** (template shows no section numbers anywhere). | all pages |

## F. In-text Citations

| ID | Rule | Source |
|----|------|--------|
| F1 | Parenthetical citations: **parentheses around author last name(s) + published year, separated by a comma.** Example: `(Davenport & Harris, 2007; Hopkins et al, 2010)`. | p.4 |
| F2 | Multiple sources inside one parenthesis separated by **semicolons**. | p.4 (example) |
| F3 | Two authors joined with **&**; 3+ authors use **et al.** | p.4, ex. p.5 |
| F4 | Narrative form (author name used as sentence subject) keeps only the year in parentheses, e.g. "Smith & Smith (2010)". | ex. p.5 |

## G. Footnotes, Equations, Appendices

| ID | Rule | Source |
|----|------|--------|
| G1 | **Do NOT use footnotes.** Use bracketed inline text `[text text text]` where a footnote would go. | p.4 |
| G2 | Equations on **separate lines, numbered consecutively**, equation number **in parentheses, right-aligned**. | p.4 |
| G3 | Appendices (if any): first-level heading **"APPENDIX"**, placed **after the body and before References**; number multiple appendices consecutively. | p.4 |

## H. Tables & Figures

| ID | Rule | Source |
|----|------|--------|
| H1 | Tables and figures are **numbered**. | ex. p.5–6 |
| H2 | Caption format **"Table N: ..."** / **"Figure N: ..."** (colon), **centered**. | ex. p.5–6 |
| H3 | Caption sits **ABOVE** the object — for BOTH tables and figures in the worked example. | ex. p.5–6 |
| H4 | Place figures/tables **as close as possible to where they are first cited**. | p.3 |
| H5 | Confirm figures still render correctly **after** PDF conversion. | p.3 |

## I. References (Bibliography)

| ID | Rule | Source |
|----|------|--------|
| I1 | Heading is **"REFERENCES"** (L1: ALL CAPS, bold, left). | p.4, ex. p.7 |
| I2 | Include **only references cited** in the text. | p.4 |
| I3 | Listed at the **end** of the paper, **alphabetical order**. | p.4 |
| I4 | **APA-style** entries (see p.4 examples: author(s), (year), title in italics, source). | p.4 |
| I5 | If references can't be included (e.g. file-size limit), insert "References available upon request." | p.4, ex. p.7 |

## J. Cross-references (derived rule — root of the user's question)

| ID | Rule | Source |
|----|------|--------|
| J1 | Because **sections are unnumbered (E4)**, you cannot cite a section by number. Refer to sections **by name** (the template intro example says "...as shown in the X section"), not "Section 3". | derived from E4 |
| J2 | Because **tables and figures ARE numbered (H1)**, cite them by number — "Table 1", "Figure 1". These references are valid and should be kept. | derived from H1 |
