# TES: Transfer Evaluation System

## Source scope

This file preserves the official product description needed to evaluate the ACOSUS comparison table.
Marketing forms, event listings, navigation, testimonials, and unrelated footer content were omitted.

## Documented purpose and users

CollegeSource presents TES as a transfer-articulation system for higher-education staff.
The official page describes workflows for researching transfer credit, routing and tracking course evaluations, managing course equivalencies, and communicating approved results publicly.

## Documented capabilities

- Search course descriptions and institutional catalog information.
- Route proposed equivalencies to faculty and record evaluation decisions.
- Create, update, group, retrieve, and publish course equivalencies.
- Compare catalog editions and identify course changes.
- Use algorithmic suggestions to locate potential equivalencies for staff review.
- Exchange transfer information with Transferology and external systems.

## Relevance to the ACOSUS paper

The official description supports characterizing TES as a staff-facing evaluation and equivalency-management system.
It does not describe a student survey workflow or a transfer-readiness measure.
